# Helia V1 Roadmap (Product Manager — draft seed for loop kickoff)

> Status: awaiting live PM agent refinement in `eve` REPL. This draft unblocks Coder discussion only after PM agent saves `02-roadmap.md` via tools.

## Vision
A mobile personal health OS that unifies Gabit, Ultrahuman, Google Fit, and Apple Health into one weekly picture — with dietitian-style guidance and autonomous nudges.

## V1 scope (P0)
1. Mobile PWA shell (bottom tabs, installable)
2. Connect toggles for Gabit, Ultrahuman, Google Fit, Apple Health
3. Today: steps, calories, water, temperature
4. Eat: food log + macros
5. Labs: blood markers + flags + disclaimer
6. Week: summary brief
7. Assistant: diet recommendations + nudge simulation
8. Autonomous nudges: hydrate on high/low temp; move when sedentary

## P1 (stretch)
- Real HealthKit / Health Connect / partner OAuth
- Native store wrappers

## Cuts
- Diagnosis, prescriptions, clinical decision support
- Full multi-device historical backfill beyond demo data

## Milestones
1. Feedback locked (User) — done seed
2. Roadmap approved (PM)
3. Slice implemented (Coder)
4. QA pass
5. User acceptance → **gate_open**
6. Only then: declare V1 app ship
